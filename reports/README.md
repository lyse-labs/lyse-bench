# Reports

This directory holds weekly Bench reports, committed automatically as
`reports/weekly/YYYY-Www.md` (ISO week number) by Lyse's Bench automation.

Each report summarizes that week's run: verdict, audits attempted/succeeded,
LLM expert grades, newly detected gaps, resolutions, and any calibration
(`K`) refit. See [`methodology.md`](../methodology.md) for what's measured
and how the verdict is computed.

There is no `tier1/`, `tier2/`, or `diffs/` subdirectory here — only `weekly/`.
