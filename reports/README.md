# Reports

This directory holds Bench reports auto-generated by GitHub Actions cron jobs in [`lyse-labs/lyse`](https://github.com/lyse-labs/lyse/tree/main/.github/workflows).

## Layout

```
reports/
  tier1/
    YYYY-MM-DD.json     # Full run report (BenchRunReport)
    YYYY-MM-DD.jsonl    # One result per line
    YYYY-MM-DD.md       # Human-readable summary
    latest.json         # symlink to most recent run
  tier2/
    YYYY-WW.json        # Weekly (ISO week number)
    YYYY-WW.jsonl
    YYYY-WW.md
    latest.json
  diffs/
    YYYY-MM-DD-tier1.md # Week-over-week diff
    YYYY-WW-tier2.md
```

## First runs

The first reports land within 24 hours of this repo's creation when the nightly tier-1 cron fires. Weekly tier-2 reports start the following Monday.

If no report has appeared after 48 hours, check the workflow runs at:
https://github.com/lyse-labs/lyse/actions/workflows/bench-tier1-nightly.yml
